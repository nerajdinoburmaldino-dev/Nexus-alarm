NEXUS ALARM — проект Android-приложения

ВАЖНО:
- Это исходный проект, не готовый APK.
- APK собирается в облаке GitHub Actions, поэтому компьютер не нужен.
- Для реального будильника Android должен разрешить точные будильники,
  уведомления и полноэкранное уведомление.
- Некоторые производители (включая TECNO) могут ограничивать фоновые
  процессы. После установки отключите оптимизацию батареи для приложения,
  если такая настройка доступна.
- Для надёжности проверьте будильник на 2–3 минуты вперёд.

СБОРКА С ТЕЛЕФОНА:
1. Создайте аккаунт GitHub или войдите в существующий.
2. Создайте новый пустой репозиторий, например nexus-alarm.
3. Распакуйте архив на телефоне.
4. В браузере откройте репозиторий → Add file → Upload files.
5. Загрузите ВСЁ содержимое папки проекта, включая скрытую папку .github.
   Если мобильный сайт не показывает скрытые файлы, включите «Версия для ПК»
   или используйте приложение/файловый менеджер, который показывает .github.
6. Нажмите Commit changes.
7. Откройте вкладку Actions → Build NEXUS ALARM APK → Run workflow.
8. Дождитесь зелёной галочки. Откройте завершённый запуск.
9. Внизу страницы Artifacts скачайте NEXUS-ALARM-debug.zip.
10. Распакуйте его и установите app-debug.apk. Разрешите установку
    из этого источника, если Android спросит.

ПЕРВОЕ ЗАПУСКАНИЕ:
1. Откройте NEXUS ALARM.
2. Разрешите уведомления.
3. Разрешите точные будильники.
4. Разрешите полноэкранные уведомления, если Android предложит.
5. Выберите время и мелодию → Сохранить будильник.
6. Проверьте работу на ближайшие 2–3 минуты.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ:
- Один ежедневный будильник.
- Кнопка «Ещё 5 минут» и выключение.
- Выбранный аудиофайл сохраняется через системный выбор файлов.
- Это минимальная первая версия; интерфейс Liquid Glass реализован
  в стиле тёмного стекла, но без сложных 3D-эффектов.
